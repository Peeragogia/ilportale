# Runtime reference workspace

Use this directory on the persistent Blender workspace.

- `user-photos/`: untouched originals from Fabrizio.
- `normalized/`: EXIF-corrected working copies.
- `crops/`: modelling crops/details.
- `measurements/`: field measurement files/CSV.
- `public/`: optional cached public references only where licensing permits.
- `dossier/`: machine-generated coverage reports.
- `renders-reference/`: Blender validation renders.

Do not put third-party copyrighted reference images into Git without permission.
