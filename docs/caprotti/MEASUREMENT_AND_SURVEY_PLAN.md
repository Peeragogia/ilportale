# Measurement and Field Survey Plan

The goal is not a conservation survey. The goal is enough trustworthy geometry to calibrate the Blender reconstruction and test the Portale installation.

## Minimum measurements with highest value

If only a few measurements can be taken, prioritise:

1. **overall width of one accessible façade**;
2. **clear width + height of one principal doorway/opening**;
3. **interior clear width**;
4. **interior clear depth**;
5. **floor-to-ceiling / floor-to-cornice height** if safely measurable;
6. **stair width** and approximate total rise.

One reliable dimension can globally scale the proportional model; two or three independent dimensions let us validate it.

## Photo protocol

For each façade:

- one as square-on as possible;
- one wider context shot;
- one 3/4 corner view from each side;
- avoid 0.5× ultra-wide when possible;
- preserve original files and EXIF;
- do not crop before upload.

Interior:

- photograph all four directions from roughly the centre;
- ceiling and floor;
- corners/reveals;
- services and existing obstacles;
- doorway/threshold.

Detail set:

- glazing frame + circular node;
- column shaft + capital;
- cornice/frieze;
- relief panel;
- statue front and side;
- balustrade module;
- stair/handrail.

## Measurement register

Every field dimension should record:

| field | example |
|---|---|
| element | front opening width |
| value | 1.42 |
| unit | m |
| method | tape |
| source | FT field survey 2026-10-xx |
| confidence | high |
| photo anchor | FRONT_03 |
| notes | measured between inner jambs |

## Photogrammetry caution

Do not derive exact dimensions from a single perspective image. Multi-view image matching can help with ratios, but every metric estimate must be labelled `ESTIMATED` until tied to a known measurement.

## Coverage gate

A serious interior placement study should not start until at least:

- one exterior dimension;
- one interior width/depth anchor;
- one doorway/opening dimension;
- at least two interior wide-angle references

are available.
