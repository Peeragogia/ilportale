# Source Register

Every source is listed for an evidentiary reason. “Supports” means the source can legitimately be used for that claim; it does not mean every detail in the source is accepted as fact.

## S00 — Original Il Portale paper
**File:** `source-material/Peeragogy_on_Music.pdf`  
**Author:** Fabrizio Terzi  
**Proposal filed:** 2013; journal publication: 2016  
**Supports:** “Learning City Point”; location at Parco Comunale “dei Caprotti”, Bergamo, Via Tasso; music learning in a peeragogical style; original physical/digital system concept.  
**Role:** primary source for project intent.
