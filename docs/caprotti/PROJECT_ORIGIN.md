# Project Origin — Il Portale before the reconstruction

The reconstruction work is not inventing a new location for Il Portale. The original project already named Parco Caprotti as its intended site.

## Source

Bundled source: [`source-material/Peeragogy_on_Music.pdf`](source-material/Peeragogy_on_Music.pdf)  
Original paper: **Fabrizio Terzi, “Peeragogy on Music / Il Portale”, 2013 proposal, published in the Peeragogical Journal in 2016.**

## Source-derived project facts

The paper presents Il Portale as a music-learning device/environment combining:

- an architectural/ornamental drop-shaped structure;
- audio reproduction;
- a large digital display;
- MIDI keyboard and digital pedals;
- a computing unit;
- web interaction and remote/tutorial learning;
- audio-video simultaneity during musical practice;
- a gallery/display function when not used for musical execution.

The paper explicitly labels the project abstract as **“Learning City Point”**.

The proposed solution states that the project would create opportunities for participants to **learn music modules in a peeragogical style**.

The location is explicitly given as:

> **Parco Comunale “dei Caprotti” — Bergamo — Via Tasso.**

This is the key continuity principle for the 2026 reconstruction: the Tea Pavilion is not a decorative location selected after the fact. It provides the architectural setting for the civic learning point already envisioned in the original project.

## Design continuity question

The 2026 project should therefore ask:

> How can the original learning-device concept become a credible civic music-learning installation inside the real Tea Pavilion, without pretending that the 2013 hardware assumptions are still current?

This means preserving the concept while allowing the physical interface, display technology, acoustics, accessibility and digital learning layer to evolve.
