\section{Contemporary Spatial Exploration: Parco Caprotti}\label{sec:caprotti}

The ongoing project phase explores the Tea Pavilion (Padiglione del T\`e)
in Parco Caprotti, Bergamo, as a candidate physical host for the Civic
Music Learning Point.  This exploration is documented separately in the
project's research dossier:

\begin{quote}
\url{https://github.com/Peeragogia/ilportale/tree/main/docs/caprotti/}
\end{quote}

The dossier contains the evidence-based reconstruction of the pavilion's
architecture, a proportional Blender blockout, verification renders, and a
quality review.  The building is a small glazed neo-Renaissance pavilion
(c.\ 1890--1891), embedded in a romantic English-style garden with a pond,
grotto, statues, and mature vegetation.

The pavilion was chosen because:

\begin{itemize}
    \item The 2013 filing already identified Parco Caprotti as the intended
        location (section~\ref{sec:origin}).
    \item The building is architecturally transparent, historically small,
        and has documented recent cultural reuse (Contemporary Locus~15,
        2023).
    \item It offers a visible but contained intervention scale, appropriate
        for a prototype of a civic music learning point.
\end{itemize}

The architectural description of the pavilion is not repeated here; the
dossier is the authoritative reference.  Any integration of the pavilion's
geometry, visual analysis, or measurement data into this publication will
be added in a later revision, after field verification.
